# limpiezaGoogleFotos

Proyecto para limpiar y ordenar una biblioteca de Google Fotos.

## Objetivo

- Detectar fotos duplicadas o muy similares.
- Identificar capturas de pantalla, fotos borrosas y otros elementos prescindibles.
- Ayudar a ordenar la biblioteca (álbumes, fechas, etc.).

## Estado

Proyecto recién iniciado.

## Seguridad

Las credenciales de Google (`client_secret*.json`, `token*.json`, `.env`) **no** deben subirse al repositorio; ya están excluidas en `.gitignore`.
